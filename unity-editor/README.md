# Unity のエディター拡張（アバター側）

ネロのアバターを作るときに使った、Unity エディター用のスクリプトです。
どちらも Unity の上部メニュー「Nero」から実行し、アニメーションを作って `Nero_FX`（VRChat の FX レイヤー用の Animator Controller）にレイヤーを足します。
何度実行しても、同じ名前のアニメとレイヤーを作り直すだけなので、値を変えて試し直せます。

使うには、`Assets/<任意のフォルダ>/Editor/` に置きます（`Editor` フォルダの中のスクリプトは、ビルドしたアバターには含まれません）。

## NeroHoloSetup.cs — ホログラムの目

メニュー：Nero → ホログラムの目アニメを作成

フードの奥の暗闇に、目がホログラムとして浮かんでいるように見せるアニメーションを作ります。

- 目の骨（`EyeHolo`）を、6 秒で 1 往復するようにゆっくり上下させる
- 12 秒の中で 3 回、一瞬だけ横にずれて暗くなる「グリッチ」を入れる
- 動きの幅は、目のメッシュの横幅に対する割合で決める（モデルの大きさを変えても同じ見え方になる）
- 1/60 秒ごとにキーを打ち、キーのあいだは直線でつなぐ（グリッチの一瞬のずれを、なめらかにぼかさないため）
- レイヤーは Write Defaults をオフにする（ほかの表情レイヤーの値を上書きしないため）

## NeroVoiceGlow.cs — 声で光る目の輪

メニュー：Nero → 声で光の輪を光らせる

話していると、目のまわりの光の輪が明るくなるようにします。

- VRChat が用意している声の大きさのパラメーター `Voice`（0〜1）を使う
- 光の輪のマテリアル（lilToon）の「発光テクスチャ 2nd」の強さを、0（黙っている）から 1（声が大きい）まで動かす
- 2 つのアニメ（0 と 1）を 1 次元の Blend Tree でつなぎ、声の大きさに応じて中間の明るさも出す
